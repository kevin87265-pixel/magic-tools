取卦規則

1
將號碼對半分成兩段：前段為下掛，後段為上掛。
★ 若號碼是奇數無法對分，在號碼最前面加 0 再對分。
2
英文字母依下方對照表換算成數字後一併計算。
3
各段數字相加求總和：總和不足 8 → 直接取該數；總和大於 8 → 除以 8 取餘數；可被 8 整除 → 取 8。
4
得出上掛、下掛兩個數字，組合成卦象編號（上掛在前、下掛在後），查對應卦象吉凶。

取卦範例

① 銀行帳號：020310002844

對分 → 020310（下掛）｜002844（上掛）
下掛 0+2+0+3+1+0 = 6，不足 8 → 取 6
上掛 0+0+2+8+4+4 = 18，18÷8 = 2 餘 2 → 取 2
卦象得 上2／下6 → 查編號 26（澤水困）

② 電話選號：0906 887 377

對分 → 09068（下掛）｜87377（上掛）
下掛 0+9+0+6+8 = 23，23÷8 = 2 餘 7 → 取 7
上掛 8+7+3+7+7 = 32，可被 8 整除 → 取 8
卦象得 上8／下7 → 查編號 87（地山謙）

③ 車牌選號：ABF-3399

英文換數 A=1、B=2、F=6；7 位為奇數 → 前補 0
對分 → 0ABF（下掛）｜3399（上掛）
下掛 0+1+2+6 = 9，9÷8 = 1 餘 1 → 取 1
上掛 3+3+9+9 = 24，可被 8 整除 → 取 8
卦象得 上8／下1 → 查編號 81（地天泰）

先天數與後天數

體
身分證字號＝先天數：出生登記即定、終身不換，看的是天生性格、命底與原生慣性——論命時當「體」。計算機可直接輸入身分證分析（英文自動換數）。
用
手機／車牌／密碼＝後天數：可自選可更換，影響當下與未來走勢——當「用」。先天不能改，後天可以調，這正是磁場改善的施力點。
力
使用頻率＝影響力：越常用、越貼身的號碼作用越強。一般排序：手機號碼 ＞ 常用密碼 ＞ 車牌 ＞ 門牌。身分證雖屬先天，因常填寫仍持續發揮底層作用。

磁場改善與運用

原則：缺什麼補什麼、改尾不改頭、一次只補一個主軸。尾段主導近期運勢，改號優先改尾段；同時補太多星磁場反而混亂。

1
生活補數字（主力）：大部分號碼改不了，補星從生活下手——鬧鐘與提醒時間、轉帳金額尾數、紅包與定價、樓層座位、運動組數次數、擇日日期，這些每天都在選的小數字，全部可以放吉星組合。再搭配對應的人事物：補天醫→布施付出、親近療癒之人；補生氣→早起運動、親近自然與樂觀朋友；補延年→固定作息、跟隨專業前輩。
2
可換的才換：密碼、LINE ID、桌布這些自己能改的，放吉星組合或用 0／5 截斷凶星；手機門號、車牌真要換再換，不必為了改號而改號。
3
凶星也能用：知其性而駕馭——絕命敢衝，適合業務短期衝刺、開拓期；五鬼點子多，適合創意企劃；六煞異性緣，適合公關銷售。凶星怕的是不自知，不是存在本身。
4
驗證節奏：改號後以 3～6 個月為觀察期，對照「現況與過往」欄的變化；先天數（身分證）作為對照基準不動。
